# Keyboard shortcuts

`Ctrl` on Windows/Linux, `Cmd` on macOS.

| Action       | Default shortcut |
| ------------ | ---------------- |
| New request  | `Ctrl/Cmd+N`     |
| Save         | `Ctrl/Cmd+S`     |
| Send request | `Ctrl/Cmd+Enter` |
| Close tab    | `Ctrl/Cmd+W`     |
| Next tab     | `Ctrl/Cmd+Tab`   |
| Find         | `Ctrl/Cmd+F`     |
| Quick open   | `Ctrl/Cmd+P`     |
| Preferences  | `Ctrl/Cmd+,`     |

In the tree: `F2` renames, `Ctrl/Cmd+D` duplicates, `Delete` deletes, arrows navigate,
`Enter` opens. Typing letters jumps to the item that starts with them.

## Customizing

**Preferences → Shortcuts** lists every action. Click a shortcut and press the new
combination; if it already belongs to another action, the app warns you instead of
overwriting. Each shortcut has a button to return to its default, and **Reset all to
default** restores them all. The native menu is rebuilt on the spot.
