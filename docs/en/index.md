features:
  - title: Local-first
    details: Workspaces, collections and environments are folders of YAML files on your machine. One file per request.
  - title: Git-friendly
    details: Deterministic serialization — saving without changes produces identical bytes, and diffs show only what changed.
  - title: Secrets stay out of Git
    details: Secret variables go to the OS keychain, never to YAML.
  - title: Scripts and tests
    details: Sandboxed JavaScript before and after every request, with assertions and variables shared across requests.
  - title: Imports what you already have
    details: Postman, Insomnia, OpenAPI and cURL.
  - title: English and Portuguese
    details: The interface and this documentation in both languages.
