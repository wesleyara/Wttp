# Atalhos de teclado

`Ctrl` no Windows/Linux, `Cmd` no macOS.

| Ação           | Atalho padrão    |
| -------------- | ---------------- |
| Nova request   | `Ctrl/Cmd+N`     |
| Salvar         | `Ctrl/Cmd+S`     |
| Enviar request | `Ctrl/Cmd+Enter` |
| Fechar aba     | `Ctrl/Cmd+W`     |
| Próxima aba    | `Ctrl/Cmd+Tab`   |
| Buscar         | `Ctrl/Cmd+F`     |
| Busca rápida   | `Ctrl/Cmd+P`     |
| Preferências   | `Ctrl/Cmd+,`     |

Na árvore: `F2` renomeia, `Ctrl/Cmd+D` duplica, `Delete` exclui, setas navegam,
`Enter` abre. Digitar letras salta para o item que começa com elas.

## Personalizando

**Preferências → Atalhos** lista cada ação. Clique no atalho e pressione a nova
combinação; se ela já pertencer a outra ação, o app avisa em vez de sobrescrever. Cada
atalho tem um botão para voltar ao padrão, e há **Reset all to default** para todos. O
menu nativo é reconstruído na hora.
